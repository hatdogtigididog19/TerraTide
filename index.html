How to use this prototype

1. Explore projects: Search and filter sample projects.

2. Open a project: Select “View project” to read details.

3. Try Project Pooling: Enter a sample amount and preview a simulated contribution.

4. Follow TideTrace: View sample progress updates.

5. Submit a project: Try the project-owner form to see the flow.

All sample data is illustrative. No money is transferred, and no data is sent to a server.
